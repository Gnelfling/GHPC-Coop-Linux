# 0.9.9.19 — Mechanical autoload and mission browser

- Mechanical autoload recovery now supports the local player in solo training, including one-vehicle missions. A local T-80B test was reported working. Native reload duration, ammunition and equipment restrictions remain in use.
- F8 mission selection adds search, clearer theater/day-night labels and a scrollable native mission briefing. Installed English or Korean-patched game assets supply the briefing text.
- Friendly formation information distinguishes platoons and vehicles; missing data is shown as unavailable instead of zero. Some previews and counts are unavailable before loading.

## Known limitations
- Intermittent third-person firing failure after reload is still under investigation; switching into the sight and back was reported to restore firing. This release does not claim a fix.
- Guest autoload, crew audio, AAR hit rays, nameplates and multiplayer performance still require live testing. English briefing display has not been visually verified.
- Build and automated fixtures passed, including 34 reload-policy cases. This is not a live Steam/Unity gameplay certification.
