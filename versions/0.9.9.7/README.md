# GHPC Unofficial Co-op 0.9.9.7

Experimental Steam and Direct IP co-op, up to four players. Each player controls one eligible friendly vehicle. Same-platoon vehicles are preferred, with other friendly platoons supplying additional seats. Native platoon membership is preserved.

Host: enter a mission, press F8, create a Steam or Direct IP room. Guests join from the main menu. F9 toggles nameplates; Shift+F9 toggles your own name.

Use the desktop launcher's Check Updates / Update and Play with the game closed. All players must use a compatible release (protocol 18). Use Install.cmd from the Setup ZIP for initial installation or to repair a modified/test DLL or an older broken launcher.

See CHANGELOG.md for changes and limitations, TEST-RESULTS.md for the actual verification scope, and REPRODUCIBLE.md for building the DLL. The Source ZIP excludes proprietary game and loader assemblies; local references are required. SHA-256 verifies file identity, not safety.
